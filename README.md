## Run locally

Requires Node.js, with no dependencies or build step:

```sh
node start.mjs
```

Open http://127.0.0.1:4173.

The initial language follows the device's primary language: Russian for `ru`, English otherwise. Manual selection is remembered. A project can be linked directly, for example `?project=claw&lang=en#project-case`.

GitHub Pages publishes the `main` branch from the repository root. The `.nojekyll` file enables direct static publishing.

## Visual system

Onest for reading and UI, Unbounded for display headings, with locally served Latin/Cyrillic fonts. Five monochrome company marks use a staggered entrance, hover feedback and an animated playhead, with a pause toggle, reduced-motion support and offscreen suspension. The Russian and English profile text has been editorially rewritten.

Font licenses and logo sources are documented in `ASSETS.md`.
